## Featured projects

### [Smart Logistics System](https://github.com/Vanshchandel17/smart-logistics-system)

<a href="https://github.com/Vanshchandel17/smart-logistics-system"><img src="assets/logistics.svg" width="100%" alt="Illustration for Smart Logistics System" /></a>

An interactive delivery-planning dashboard with Leaflet maps, OpenRouteService routing, and Dijkstra-based route optimization.

**Stack** · React · Vite · Tailwind CSS · Node.js · Express · MongoDB

### [HabitFlow](https://github.com/Vanshchandel17/habit-launcher)

<a href="https://github.com/Vanshchandel17/habit-launcher"><img src="assets/habit.svg" width="100%" alt="Illustration for HabitFlow" /></a>

A full-stack habit tracker with a completion calendar and progress dashboard. A dynamic programming algorithm computes current and longest streaks.

**Stack** · React · Tailwind CSS · Node.js · Express · MongoDB

### [Digital Nutrition Label](https://github.com/Vanshchandel17/digital-nutrition-label)

<a href="https://github.com/Vanshchandel17/digital-nutrition-label"><img src="assets/nutrition.svg" width="100%" alt="Illustration for Digital Nutrition Label" /></a>

A Chrome extension built around a popup, a page content script, and a background service worker.

**Stack** · JavaScript · Chrome Extensions · Manifest V3
