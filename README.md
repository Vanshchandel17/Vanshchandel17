## Featured projects

### [Smart Logistics System](https://github.com/Vanshchandel17/smart-logistics-system)

An interactive logistics dashboard for planning delivery routes. It uses Leaflet for maps, OpenRouteService for routing, and Dijkstra’s algorithm for delivery optimization.

**Stack** · React · Vite · Tailwind CSS · Node.js · Express · MongoDB · Leaflet

### [HabitFlow](https://github.com/Vanshchandel17/habit-launcher)

A habit tracker with calendar views and progress dashboards. It uses dynamic programming to calculate streaks from completion history.

**Stack** · React · Tailwind CSS · Node.js · Express · MongoDB

### [Digital Nutrition Label](https://github.com/Vanshchandel17/digital-nutrition-label)

A Chrome extension project with a popup, a page content script, and a background service worker.

**Stack** · JavaScript · Chrome Extensions (Manifest V3)
